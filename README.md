Personal Portfolio Website

A personal portfolio website built using React to showcase my skills, projects, and learning journey as a Computer Science student.

Features

- Home section introducing me
- About section
- Skills section
- Projects section
- Contact section
- Responsive layout
- Navigation using React Router

Technologies Used

- React
- JavaScript
- HTML
- CSS
- Vite

Getting Started

To run this project locally:

1. Clone the repository.

2. Open the project folder in the terminal.

3. Install the dependencies:
   
   npm install

4. Start the development server:
   
   npm run dev

5. Open the local address displayed in the terminal in your browser.

Purpose

This project was developed to practise React concepts and build a personal portfolio showcasing my skills and projects.
